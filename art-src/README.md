# Исходники графики

Сюда кладутся оригиналы из ChatGPT в PNG. Рядом с каждой картинкой — файл `.md` с тем же именем: промпт, формат, статус.

- `bg/` — фоны и сцены
- `obj/` — предметы на прозрачном фоне
- `portraits/` — персонажи
- `probes/` — пробы и референсы, в игру не идут
- `inbox/` — сюда можно загружать новые картинки как есть, без обработки

Игра берёт не эти файлы, а сжатые копии из `public/assets/`. Их делает команда `npm run assets`.
Имена файлов — по id из стайл-гайда (`docs/styleguide.md`).
