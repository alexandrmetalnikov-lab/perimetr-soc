# Периметр SOC — инструкции для Claude

Игра в духе Papers, Please для специалистов по ИБ. Владелец — Александр, общаемся по-русски и на «ты».
Он эксперт по ИБ и регуляторике (КИИ, ФСТЭК, ПДн), сам пишет кейсы и генерирует графику в ChatGPT; код делает Claude.

## Стек

Vite + Svelte 5 (руны) + TypeScript. Звук — пока синтез в `src/lib/audio.ts`, дальше файлы. Сборка с `base: './'`,
одна и та же `dist/` идёт на GitHub Pages и в архив для itch.io.

## Устройство

- `src/content/` — загрузка YAML, типы, помощники (условия, улики, значения по сменам).
- `src/game/engine.ts` — правила игры без DOM, покрыты тестами `engine.test.ts`. Любая правка правил — сначала тест.
- `src/game/Game.svelte` — сцена, смена, оверлеи (утро, отчёт, бюджет, финал); `CaseDoc` — объект на столе;
  `Binder` — справочник; `Rich` — текст с уликами `[[ключ|текст]]`.
- Сохранение — в localStorage между сменами (`toSave`/`fromSave`), смена при загрузке начинается с утра.

## Правила

- В `main` не коммитим: ветка + pull request. Перед PR: `npm run content:check && npm test && npm run check && npm run build`.
- Контент (кейсы, регламенты, справочники) живёт в `content/*.yaml`, не в коде. Формат — `content/README.md`.
- Каждый кейс: решение выводится из того, что на экране и в справочнике; у атаки есть легитимный двойник;
  в разборе — реальный инцидент и источник. Факты об инцидентах проверять, не выдумывать.
- Графика: исходник в `art-src/<группа>/<id>.png` + `<id>.md` с промптом, затем `npm run assets`.
  Стиль и промпты — `docs/styleguide.md`. Текст на картинках не допускается, весь текст — в HTML.
- Координаты предметов на столах — `src/scene/layouts.ts`. Если стол перегенерирован, правится только там.
- Прототипы в `public/prototypes/` — архив, не редактировать.
- Секреты (ключ itch.io и т. п.) — только в GitHub Secrets.
- Целевые устройства: телефон в Telegram и компьютер. Проверять обе раскладки (`land` и `port`).
